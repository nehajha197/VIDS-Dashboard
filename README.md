# VIDS Dashboard

A web-based VIDS (Vehicle Identification and Detection System) Dashboard developed to visualize and monitor vehicle traffic data through interactive dashboards and charts.

# Features

- Vehicle traffic analytics dashboard
- Vehicle class and traffic count visualization
- Device status monitoring
- Violation and event data
- Passing vehicle statistics
- Interactive charts and data visualization
- SQL Server data integration
- Stored procedure-based data retrieval using Dapper

# Technologies Used

- C#
- .NET / ASP.NET Core
- Blazor
- MudBlazor
- JavaScript
- SQL Server
- Dapper

# Project Purpose

This project was developed as a practical application to work with traffic-related data, database integration, APIs, data visualization, and modern .NET web development.

# Database

The application uses SQL Server for storing and retrieving VIDS data. Dapper and SQL stored procedures are used for efficient database operations.

# Author

Developed as a .NET development project to gain practical experience with Blazor, .NET, SQL Server, Dapper, and dashboard development.
